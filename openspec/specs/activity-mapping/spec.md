## Requirements
### Requirement: Map CreateActivityRequest to Activity

The system SHALL provide a mapping operation that converts a `CreateActivityRequest` DTO into a new `Activity` domain entity. The resulting `Activity` SHALL have its `Id` generated by the entity itself (not sourced from the request). The fields `IsCancelled` SHALL default to `false`. All other fields shared between the DTO and entity (`Title`, `Date`, `Description`, `Category`, `City`, `Venue`, `Latitude`, `Longitude`) SHALL be copied verbatim.

#### Scenario: All required fields produce a valid Activity

- **WHEN** a `CreateActivityRequest` with all fields populated is passed to `IActivityMapper.ToActivity()`
- **THEN** the returned `Activity` has `Title`, `Date`, `Description`, `Category`, `City`, `Venue`, `Latitude`, and `Longitude` equal to the corresponding request fields
- **THEN** `Activity.IsCancelled` is `false`
- **THEN** `Activity.Id` is a non-empty GUID string (generated by the entity, not from the request)

#### Scenario: Numeric fields are copied exactly

- **WHEN** `CreateActivityRequest.Latitude` is `51.5074` and `Longitude` is `-0.1278`
- **THEN** the returned `Activity.Latitude` is `51.5074` and `Activity.Longitude` is `-0.1278`

---

### Requirement: Update Activity from another Activity

The system SHALL provide a mapping operation that copies mutable property values from a source `Activity` onto an existing destination `Activity` instance. The destination `Activity.Id` SHALL be preserved unchanged. The properties copied SHALL be: `Title`, `Date`, `Description`, `Category`, `IsCancelled`, `City`, `Venue`, `Latitude`, `Longitude`.

#### Scenario: Properties are overwritten on destination

- **WHEN** `IActivityMapper.UpdateActivity(source, destination)` is called with source having different `Title` and `Description` than destination
- **THEN** `destination.Title` equals `source.Title`
- **THEN** `destination.Description` equals `source.Description`

#### Scenario: Destination Id is never overwritten

- **WHEN** `IActivityMapper.UpdateActivity(source, destination)` is called and `source.Id` differs from `destination.Id`
- **THEN** `destination.Id` retains its original value after the call

#### Scenario: IsCancelled is carried over in updates

- **WHEN** `source.IsCancelled` is `true`
- **THEN** `destination.IsCancelled` is `true` after the call

---

### Requirement: Mapper is registered in the DI container

The system SHALL register `IActivityMapper` in the ASP.NET Core DI container so that MediatR handlers can receive it via constructor injection. The registration scope SHALL be `Scoped`.

#### Scenario: Handlers resolve IActivityMapper from DI

- **WHEN** the application starts and `CreateActivity.Handler` or `UpdateActivity.Handler` is resolved from the service provider
- **THEN** an `IActivityMapper` instance is successfully injected with no `InvalidOperationException`
